# WORD WEREWOLF

3〜5人で遊べるオンライン・ワード人狼です。ユーザー登録不要で、ブラウザごとに発行されるゲストIDを使って戦績を保存します。

## 必要環境

- Python 3.10以上
- pip
- モダンブラウザ（Chrome / Edge / Firefox など）

## 起動方法（Windows）

```powershell
# ZIPを展開してプロジェクトフォルダへ移動
cd word_werewolf

# 仮想環境を作成
py -m venv .venv

# 仮想環境を有効化
.venv\Scripts\Activate.ps1

# ライブラリをインストール
python -m pip install -r requirements.txt

# 起動
python app.py
```

ブラウザで http://127.0.0.1:5000 を開きます。

## 遊び方

1. 1人が「ルームを作成する」を押します。
2. 表示された5文字のルームコードを友達に共有します。
3. 他のプレイヤーはコードを入力して参加します。
4. 3〜5人になったらホストがトーク時間とカテゴリーを設定して開始します。
5. 各自がお題を確認し「準備完了」を押します。
6. トーク終了後に投票し、最多得票者を追放します。
7. 人狼が追放された場合、人狼は市民のお題を当てる最終回答を行います。
8. 結果が表示され、戦績が保存されます。

## Renderでインターネット公開する

1. このプロジェクト一式をGitHubの新しいリポジトリにアップロードします。
2. Renderにログインし、New → Blueprintを選び、GitHubリポジトリを接続します。
3. リポジトリ内の `render.yaml` を読み込ませてデプロイします。
4. デプロイ完了後に表示される `https://...onrender.com` のURLを友達に共有します。

`render.yaml` はPython 3.12、Gunicorn（threaded worker）、ヘルスチェック、ランダムな `SECRET_KEY` を設定します。RenderのWebSocket接続を利用するため、公開後の接続確認は複数のネットワークから行ってください。

**無料プランの注意点**：一定時間アクセスがないとサービスがスリープし、次回アクセス時に起動待ちが発生します。また、無料インスタンスのローカルファイルは永続保存先ではありません。戦績データ（SQLite）は再デプロイ・再起動等で失われる可能性があります。ルーム情報もメモリ上にあるため、サーバー再起動で進行中のゲームは終了します。継続的に戦績を保存したい場合は、永続ディスクまたは外部データベースの導入が必要です。

## 同じネットワーク内の別端末から遊ぶ

サーバーを起動したPCのローカルIPアドレスを調べ、同じWi-Fi内の端末から `http://PCのIPアドレス:5000` にアクセスします。

例：
```powershell
ipconfig
```

WindowsファイアウォールでPythonの通信許可が必要になる場合があります。

インターネット越しに友達と遊ぶ場合は、上記のRender公開手順を利用してください。

## 仕様

- 人狼は毎ゲーム1人
- 参加人数は3〜5人
- トーク時間は15〜300秒
- 投票は匿名
- 最多得票者を追放
- 同票の場合は決選投票
- 決選投票も同票なら人狼側勝利
- 人狼が追放された場合、市民のお題を当てれば人狼側の逆転勝利
- 市民側勝利は各市民に2ポイント、人狼側勝利は人狼に3ポイント
- 戦績はSQLiteに保存

## 注意点・今後の改善候補

- ルーム情報はメモリ上に保持されるため、サーバー再起動で進行中のルームは消えます。
- 戦績は `word_werewolf.db` に保存されます。
- ゲストIDはブラウザのlocalStorageに保存されます。ブラウザデータを消すと別ユーザー扱いになります。
- 本バージョンは学習・試作向けです。公開運用前に、再接続、ルームの期限切れ、通信切断時の進行、レート制限、認証・不正対策を追加してください。
- タイマーはサーバーが管理します。投票時間切れ時は未投票者に対してランダムな有効投票を補完し、ゲーム進行が止まらないようにしています。
